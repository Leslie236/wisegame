# WISE 21 · 休闲牌室

Vue 3 + TypeScript 编写的中文单人二十一点小游戏，仅使用虚拟筹码。

## 本地运行

```sh
npm install
npm run dev
```

打开终端输出的本地地址。

```sh
npm run build
npm run test:unit -- --run
```

## 功能与规则

- 炭黑深色、经典绿桌、午夜蓝、暖色浅色四套主题，默认炭黑深色，选择自动保存。
- 初始 1,000 筹码，可选择 10 / 50 / 100 / 200 下注，支持重置筹码。
- 支持要牌、停牌、起手加倍、分牌和投降；庄家在所有 17 点（含软 17）停牌。
- 天生 Blackjack 按 3:2 净赔付；普通获胜按 1:1，平局退回下注。
- 每局重新洗一副 52 张牌，每局限分一次，分 A 只补一张；分牌后的 21 点按普通牌结算。投降仅限未分牌的起手，退回一半下注。不提供保险。
- 余额保存在浏览器本地；刷新会结束当前牌局，已下注筹码不退回。局数统计仅限本次打开。
- 响应式布局，适配手机和桌面屏幕。
