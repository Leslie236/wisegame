# WISE 牌室 · 休闲牌室

Vue 3 + TypeScript 编写的单机休闲牌室，包含**二十一点**和**德州扑克**两款游戏，仅使用虚拟筹码。

## 本地运行

```sh
npm install
npm run dev
```

打开终端输出的本地地址，可在顶部「21 点 / 德州扑克」之间切换。

```sh
npm run build
npm run test:unit -- --run
```

## 二十一点

- 炭黑深色、经典绿桌、午夜蓝、暖色浅色四套主题，默认炭黑深色，选择自动保存。
- 初始 1,000 筹码，可选择 10 / 50 / 100 / 200 下注，支持重置筹码。
- 支持要牌、停牌、起手加倍、分牌和投降；庄家在所有 17 点（含软 17）停牌。
- 天生 Blackjack 按 3:2 净赔付；普通获胜按 1:1，平局退回下注。
- 每局重新洗一副 52 张牌，每局限分一次，分 A 只补一张；分牌后的 21 点按普通牌结算。投降仅限未分牌的起手，退回一半下注。不提供保险。

## 德州扑克

- 4 人桌：你 + 三位 NPC（紧凶、松凶、跟注站）。NPC 从 40 个名字中随机取名，同桌不重名；筹码归零后的新玩家也会随机取一个不同的名字。
- 无限注德州，盲注 10 / 20；按钮每手顺时针移动。
- 筹码与二十一点**共用同一个余额**；AI 筹码归零后离桌，下一手换上新玩家，随机携带 1,000～5,000 筹码（剩余 1～19 筹码继续参赛），你可以在筹码不足时重新买入 1,000。
- 支持弃牌、过牌、跟注、下注、加注、全下；有主池 / 边池、平分底池和奇数筹码分配。
- 作弊换牌：所有玩家每局可在自己的行动回合换一张底牌，随机从剩余牌堆抽取，旧牌弃置。花费当前剩余筹码的 10%（向上取整），10% 不足 100 则不可使用；费用不进入底池，计入净输赢。NPC 每次行动有 25% 概率在符合条件时使用。能力定义与规则集中在 `src/game/poker/cheats.ts`，便于后续扩展。
- 摊牌时翻开剩余玩家底牌，显示中文牌型标签，高亮赢家与其最佳五张。
- 键盘快捷键：F 弃牌、C 过牌/跟注、R 加注、A 全下、Esc 关闭弹窗；打开玩法说明时 AI 会暂停思考。
- 第一版对短全下采用简化规则：任何全下加注都会重新打开行动。
- 手牌进行中刷新页面或切换到二十一点视为弃牌，已投入底池的筹码不会退回（与二十一点刷新后本局下注不退一致）。

## 项目结构

```
src/
├── App.vue                    # 主题 + 顶部导航 + RouterView
├── views/                     # BlackjackView / PokerView
├── components/                # 二十一点组件 + poker/ 桌子、座位、牌、行动条
├── composables/               # useBlackjack / useHoldem / useWallet / useTheme
├── game/
│   ├── cards.ts               # 共享牌与洗牌
│   ├── blackjack.ts           # 二十一点规则
│   └── poker/                 # 类型、牌型评估、边池、状态机、AI
├── assets/styles.css          # 主题与全局样式
└── __tests__ / game/poker/__tests__ /  # 测试
```

## 测试

```sh
npm run test:unit -- --run
```

当前 64 个测试，覆盖二十一点、导航、扑克引擎、牌型、边池、AI 决策与随机对局、扑克界面、NPC 替换，以及作弊换牌的费用门槛、次数限制、牌堆唯一性、结算和 NPC 使用。

## 说明

- 纯娱乐小游戏，所有筹码均为虚拟筹码。
- 主题和筹码余额保存在浏览器本地；扑克手数、本手输赢等统计仅限本次打开。
- 这不是真钱赌博产品，不提供任何现金兑换。
